# 📘 Stock Options Learning Roadmap

> A 4-week structured plan to learn how stock option contracts work — from basic concepts to practical trading strategies.  
> Focus: Understanding, not gambling. Use paper trading only.

───────────────────────────────────────────────
## 🗓️ WEEK 1 — Foundation: What Is an Option?

**Goal:** Understand what options are, how they work, and all basic terms.

### 📖 Study
- [ ] Read: [Investopedia — Options Basics](https://www.investopedia.com/options-basics-tutorial-4583012)  
- [ ] Watch: [tastytrade “Options Basics for Beginners” playlist](https://www.youtube.com/@tastytrade)  
- [ ] Skim: *Options Made Easy* by Guy Cohen (Ch. 1–3)

### 🧩 Learn Concepts
- [ ] Calls vs. Puts  
- [ ] Strike Price, Expiration, Premium  
- [ ] ITM / ATM / OTM  
- [ ] Option contract = 100 shares  
- [ ] How to read an options chain  

### 🧪 Practice
- [ ] Open paper trading account (TD Ameritrade, Webull, etc.)  
- [ ] Look up AAPL or SPY option chains  
- [ ] Record 3 calls + 3 puts (strike, expiration, bid/ask, volume, OI)

### ✅ Checkpoint
> “A call gives the right to buy, a put gives the right to sell, and the premium is the cost for that right.”

## ⚙️ WEEK 2 — Pricing & The Greeks

**Goal:** Learn how option prices move and what affects them.

### 📖 Study
- [ ] Watch: [Option Alpha — Understanding Option Pricing](https://www.youtube.com/@OptionAlpha)  
- [ ] Read: Investopedia pages on Delta, Gamma, Theta, Vega, Rho  
- [ ] Read: Intrinsic vs. Extrinsic Value  

### 🧩 Learn Concepts
- [ ] Time Decay (Theta)  
- [ ] Directional sensitivity (Delta)  
- [ ] Volatility effects (Vega)  

### 🧪 Practice
- [ ] Simulate long call/put trades on same stock  
- [ ] Observe price/time/IV changes  
- [ ] Use [OptionStrat.com](https://optionstrat.com) to visualize payoffs  

### ✅ Checkpoint
> You can explain why one contract is more expensive than another.
