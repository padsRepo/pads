# How to Use This Book

Welcome to Operation Starship. This book is designed as a hybrid resource that combines reference material, tutorials, technical documentation, and strategic planning. Whether you're here to explore the codebase, learn a new tool, or understand a system architecture, this guide will help you navigate the content effectively.  
This book was generated using [`paddocs`](#paddocs). This frontmatter acts as a demonstration for the program, as well as further documentation of how it works.

## Structure Overview

This book is divided into the following primary sections:

- **00-front** — Frontmatter of the book.
- **10-docs** — Technical documentation, API specs, CLI commands, and definitions.
- **11-manual** — User-facing documentation structured like Unix manpages.
- **12-business** — Real-world applications and strategic thinking.
- **13-property** - Real Estate Reports, Property Management Reports, and Tenant Profiles.
- **14-trading** - Forms, reports, and logs for building your strategy and tracking your results.
- **18-tutorials** — Step-by-step walkthroughs for building or understanding components.
- **19-blog** - Raw thoughts on any subject
- **20-notes** - Daily, and weekly planning logs, and research papers.
- **99-back** — Additional resources, metadata, etc.

Each topic area may be further broken down into individual "chapters" that can stand alone.

## Navigation Tips

- **Modular Topics:** Chapters are self-contained. You can jump to what you need without reading cover to cover.
- **Code & Scripts:** Located in `assets/`, `config/`, `includes/`, and `src/` or referenced directly.
- **Command Blocks:** Any command-line examples are written as copyable blocks.
- **Warnings & Notes:** Tips, pitfalls, and important details are highlighted for quick scanning.

## Tools You’ll Need

To get the most from this book, you should have:

- A Unix-like environment (Linux/macOS or WSL)
- Familiarity with Bash and/or Python
- Tools like `pandoc`, `git`, `python`, `bash`, `flask`.

## Output Formats

This book is designed to render into:

- PDF (via Pandoc + LaTeX)
- HTML (via Pandoc or static site generators)
- Plain Markdown (for IDE or GitHub browsing)

Use [`paddocs`](#paddocs) to generate your code into your preferred format.
